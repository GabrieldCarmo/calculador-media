# Calculadora de Média em Flutter

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma calculadora de média utilizando a linguagem Dart e o framework Flutter.

O aplicativo permite inserir quatro notas e calcular automaticamente a média final, apresentando uma classificação de acordo com o resultado obtido.

O projeto foi desenvolvido como atividade da disciplina de Programação de Aplicativos Mobile (PAM), com o objetivo de praticar conceitos de programação, criação de funções, estruturas condicionais, manipulação de dados e desenvolvimento de interfaces para dispositivos móveis.

## Funcionalidades

- Inserção de quatro notas.
- Cálculo automático da média.
- Validação de notas entre 0 e 10.
- Aceitação de números decimais com vírgula ou ponto.
- Classificação do resultado:
  - R: média menor ou igual a 5.
  - B: média maior que 5 e menor que 9.
  - MB: média maior ou igual a 9.
- Exibição da média e de mensagens de acordo com o resultado.
- Botão para limpar todos os campos e realizar um novo cálculo.
